Chord library

Find a chord — everywhere it lives

Pick a root and type. Each card is a different position on the neck. Diagrams read top–to–bottom as frets and left–to–right as strings (low E → high E). The number beside the grid is the starting fret; × = mute, ○ = open.

Scale library

The whole scale, then position by position

Choose a root and scale. You get the whole neck first, then every position laid out below it — ordered from the one closest to the nut on up. Root notes are highlighted.

Pick a key and see the seven chords built from its own notes — the ones that sound “in key” together. Roman numerals show each chord's role: uppercase = major, lowercase = minor, ° = diminished.
